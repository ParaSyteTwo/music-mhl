## Cambios realizados

### Anime

- `AnimeTheme.title` y `AnimeTheme.artist` son ahora la identidad canonica de
  la cancion.
- El titulo del anime se conserva como album.
- La portada del anime se conserva en el track virtual.
- YouTube se usa para seleccionar la cancion completa.
- AnimeThemes deja de descargarse silenciosamente como cancion completa; su
  audio queda disponible como fallback TV-size.
- Los temas sin audio curado siguen siendo utilizables para buscar en YouTube.
- Se rechazo el fallback ambiguo al primer resultado de AnimeThemes.

### Desktop

- El bridge devuelve Base64 real en `data_b64`; antes devolvia hexadecimal.
- Se agrego `src/lib/binaryEncoding.ts` y su prueba.
- Se sustituyeron llamadas Python a `_yt_search` y `_score`, que no existian.
- La escritura crea el directorio, comprueba errores y se limita a la carpeta
  configurada de descargas.
- El frontend no marca una descarga completada si falla la escritura.
- AAC se deshabilito en Ajustes porque el pipeline escribia ID3 de MP3 sobre
  M4A.

### Frontend

- La biblioteca vuelve a estar accesible en `/library` y en la navegacion.
- Los errores de `audio.play()` ya no se silencian.
- La cola retira trabajos atomicamente y elimina IDs al borrar descargas.
- La restauracion Android conserva objetos `File` reales.
- El service worker solo se registra en el branch web legado.
- Se corrigieron los errores de TypeScript del updater y sus fixtures.

### Android y updater

- Restaurado el periodo obligatorio de maduracion de siete dias.
- El canal beta acepta exclusivamente prereleases.

## Deuda pendiente

1. Preparar release `1.4.5`:
   - actualizar `package.json` y `package-lock.json`;
   - actualizar Android `versionName` a `1.4.5`;
   - incrementar Android `versionCode` a `19`;
   - actualizar el User-Agent/versiones documentales que correspondan.
2. Repetir todas las verificaciones.
3. Construir ZIP portable Desktop con
   `mhl-desktop/scripts/build-portable.ps1`.
4. Construir APK release firmado con el certificado existente.
5. Ejecutar:

   ```powershell
   npm run android:prepare-release -- --apk <ruta-al-apk-firmado>
   ```

6. Confirmar en `release/`:
   - ZIP portable Windows;
   - `MHL-Music-1.4.5.apk`;
   - `MHL-Music-Android.json`.
7. Verificar SHA-256, package `com.mhl.music`, `versionCode 19`,
   `versionName 1.4.5` y certificado.
8. No publicar ni enviar un APK renombrado o sin firma validada.
