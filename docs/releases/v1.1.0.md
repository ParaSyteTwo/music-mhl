🎉 MHL Music v1.1.0 — Búsqueda inteligente y descargas más precisas

Gran mejora en el flujo de descarga: ahora la app deja de depender de una sola suposición y te muestra una lista inteligente con los mejores candidatos para que elijas la canción correcta.

✨ Novedades principales

🎯 Búsqueda inteligente de candidatos
Ahora al pulsar descargar se abre un selector con una sola lista ordenada por coincidencia real.

El sistema:
- lanza varias búsquedas por canción
- limpia título y artista antes de buscar
- mezcla resultados y elimina duplicados
- recalcula un score global
- resalta el mejor match

🏷️ Clasificación automática de resultados
Los candidatos ya no están divididos en pestañas redundantes.
En su lugar, cada resultado puede mostrarse con etiquetas como:

- `original probable`
- `cover`
- `live`
- `anime op/ed`

Además, cada candidato muestra nivel de confianza:

- `alta`
- `media`
- `baja`

🎵 Mejor detección de canciones difíciles
La búsqueda mejora especialmente en casos como:

- openings y endings de anime
- canciones con muchas versiones subidas a YouTube
- títulos ambiguos
- covers
- lives
- radio edits
- full versions

🌐 Backend web más resistente
El flujo web ahora soporta búsqueda inteligente con fallback desde `yt-stream`.

Mejoras incluidas:
- normalización de texto antes de buscar
- varias queries por canción
- ranking unificado
- fallback si el backend externo sigue con una versión vieja de `/candidates`
- errores de backend más claros

📱 Instalación APK (Android)
Descarga el archivo `MHL.Music.v1.1.0.apk` de abajo

1. En tu Android ve a `Ajustes -> Seguridad -> Fuentes desconocidas`
2. Actívalo si hace falta
3. Abre el APK descargado
4. Instala la app
5. ¡Listo!

⚠️ Requiere Android 8.0 o superior (API 26+)
