MHL Music 1.5.0 Beta 3 (Memoria Infinita)

¡Llegamos a la Fase 2! Históricamente, la aplicación limitaba tu historial a 100 canciones para evitar que la memoria del navegador colapsara. Eso se acabó. En esta Beta 3, hemos reprogramado el motor de base de datos interno desde cero.

🚀 **Poder Ilimitado**
*   **Base de Datos Asíncrona (IndexedDB):** Migramos por completo el sistema de almacenamiento. Ahora la aplicación usa una base de datos de alto rendimiento capaz de almacenar cientos de miles de registros.
*   **Adiós al límite de 100 canciones:** Ya puedes descargar toda tu biblioteca. El límite artificial ha sido completamente eliminado del código.
*   **Auto-Migración Inteligente:** Tus canciones y ajustes de la Beta 2 no se perderán. La aplicación moverá automáticamente tus datos a la nueva base de datos ultrarrápida la primera vez que la abras.
